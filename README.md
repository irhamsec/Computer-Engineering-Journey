# Computer Engineering Journey

> Documenting my complete journey from computer architecture fundamentals to firmware and embedded systems engineering.

---

## About

This repository documents my learning journey as a Computer Engineering student.

The goal is not only to build projects, but also to understand how computers work from the hardware level up to operating systems, firmware, and embedded software.

Rather than uploading only finished projects, this repository records:

- Engineering notes
- Architecture diagrams
- Practical experiments
- Source code
- Lessons learned

---

## Why This Repository Exists

Modern computers are incredibly complex systems composed of hardware, firmware, operating systems, and application software.

Instead of learning these topics in isolation, I am documenting a structured journey to understand how each layer interacts with the next.

This repository serves as both my learning journal and technical portfolio.
